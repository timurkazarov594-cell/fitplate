Добавь безопасную обработку загружаемых изображений в FitPlate.

Сервис должен принимать только фотографии еды.

Перед анализом блюда добавить проверку изображения:

— если на фото еда, продолжать анализ;
— если на фото не еда, показывать ошибку:
“Пожалуйста, загрузите фотографию блюда.”
— если на фото запрещённый или опасный контент, показывать ошибку:
“Это изображение нельзя обработать.”

Запрещённые изображения:

— насилие, кровь, травмы, расчленение;
— интимный или сексуальный контент;
— изображения несовершеннолетних в неподходящем контексте;
— незаконный контент;
— любые изображения, не связанные с едой.

Если на фото есть рука, держащая тарелку или еду, это допустимо.

Если на фото просто часть тела без еды, анализ не выполнять.

Фото не должно сохраняться навсегда.

Не сохранять оригинальные изображения пользователей в database.
Не логировать base64 изображения.
Не выводить изображение в server logs.

После анализа сохранять только результат:

— название блюда;
— калории;
— белки;
— жиры;
— углеводы;
— клетчатку;
— дату;
— userId.

Добавить лимиты загрузки:

— принимать только image/jpeg, image/png, image/webp;
— максимальный размер файла 5 MB;
— если файл больше, показывать:
“Файл слишком большой. Максимум 5 MB.”
— если формат не подходит, показывать:
“Можно загрузить только изображение.”

Добавить защиту backend.

Проверка типа файла и размера должна быть не только на frontend, но и на backend.

Если AI/moderation API возвращает ошибку безопасности, не списывать photoCredit.

Кредит списывать только после успешного анализа еды.

Добавить текст в пользовательское соглашение:

“Пользователь обязуется загружать только фотографии еды. Запрещается загружать незаконный, насильственный, интимный, оскорбительный или иной недопустимый контент. Сервис может отказать в обработке изображения без объяснения причин.”

Проверить:

— фото еды анализируется;
— фото не еды отклоняется;
— запрещённое изображение отклоняется;
— кредит не списывается при отказе;
— оригинальное фото не сохраняется в базе;
— build проходит без ошибок.

После всех исправлений создай ZIP-архив проекта.

Название архива:

FitPlate_FINAL_SAFE.zip

В архив должны войти все файлы проекта, необходимые для загрузки на GitHub и деплоя на Render.

Не включать в ZIP:

— node_modules;
— .git;
— .cache;
— dist;
— build;
— .DS_Store;
— временные файлы;
— реальные API-ключи;
— секреты;
— .env с реальными значениями.

Если нужен .env, создать только .env.example без настоящих ключей.

После создания ZIP покажи файл для скачивания.
