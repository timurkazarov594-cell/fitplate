Исправь ошибки в AI Nutrition Coach.

1. Исправить ошибку анализа блюда.

Сейчас после загрузки фото появляется экран:

“Ошибка. Не удалось проанализировать блюдо. Попробуйте снова.”

Нужно:
— найти реальную причину ошибки;
— добавить подробный console.log на backend и frontend;
— проверить API route анализа фото;
— проверить передачу изображения;
— проверить формат base64/FormData;
— проверить AI API ключ;
— проверить, что backend получает файл;
— если AI возвращает ошибку, показывать понятную причину;
— если API ключ отсутствует, показывать ошибку “AI API key is missing” в логах сервера;
— если файл не дошёл до сервера, показывать “image file missing”.

После исправления анализ должен работать так:

Пользователь загружает фото →
появляется preview →
появляется loading →
AI распознаёт блюдо →
показывает калории, белки, жиры, углеводы, клетчатку →
кнопка “Добавить в дневник”.

2. Сделать загрузку фото не только через нижнюю кнопку камеры.

Сейчас фото можно загружать только через зелёную кнопку камеры снизу.

Нужно сделать так, чтобы большая панель в блоке “Приёмы пищи сегодня”, где написано:

“Нет записей. Сфотографируйте блюдо!”

тоже была кликабельной.

При нажатии на эту большую панель должно открываться системное окно выбора фотографии, точно так же как при нажатии на нижнюю кнопку камеры.

3. Исправить file input.

Сделать один общий hidden input type=“file”, который используется и нижней кнопкой камеры, и большой панелью.

Требования:

— accept=“image/*”
— на мобильных устройствах разрешить камеру и галерею
— onChange должен срабатывать после выбора фото
— если пользователь выбирает то же фото повторно, input должен очищаться перед новым выбором
— кнопки должны вызывать fileInputRef.current.click()

4. UX.

Большая панель должна визуально показывать, что по ней можно нажать:

— cursor pointer на desktop
— лёгкий hover effect
— текст заменить на:
“Нажмите, чтобы сфотографировать или загрузить блюдо”

5. Проверка.

После исправления проверить:

— нижняя кнопка камеры открывает выбор фото;
— большая панель открывает выбор фото;
— после выбора фото появляется preview;
— анализ блюда запускается;
— ошибки не скрываются молча;
— npm run build проходит без ошибок.
